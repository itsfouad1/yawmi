# يومي | تطبيق مهام لسطح المكتب

تطبيق مهام عربي لسطح المكتب باستخدام Electron وReact وTypeScript. يعمل دون اتصال ويحفظ بياناتك تلقائيًا على جهازك.

## التشغيل

يتطلب Node.js. افتح PowerShell داخل مجلد المشروع:

```powershell
npm install
npm run desktop
```

إنشاء مثبت Windows بأيقونة واختصار:

```powershell
npm run package:win
```

يظهر المثبت داخل مجلد `release`.

## الميزات

- مهام مع وصف وتصنيف وأولوية وموعد وخطوات فرعية.
- مشاريع تجمع مهامها، ولوحة عمل بثلاث حالات: جديدة، قيد العمل، مكتملة.
- مؤقت لكل مهمة مع حفظ الوقت المسجل.
- قوائم اليوم والقادم والمتأخر والمكتمل، مع فلاتر التاريخ والتصنيف والأولوية.
- عرض تقويم أسبوعي وشهري، وتكرار يومي أو أسبوعي وتنبيهات قابلة للتأجيل.
- ملخص للإنجازات والوقت المسجل.
- ثيمات، خلفيات للحديقة، تحكم بحجم الخط وتباين أعلى.
- تصدير واستيراد CSV، ونسخ احتياطي واستعادة كاملة بصيغة JSON.
- مؤقت تركيز، حالة المزاج، حديقة الإنجاز، والمكافآت.

## اختصارات لوحة المفاتيح

- `Ctrl + N`: إضافة مهمة.
- `Ctrl + K`: الانتقال إلى البحث.
- `Ctrl + Shift + F`: تشغيل أو إيقاف جلسة التركيز.

## نقل البيانات بين الأجهزة

استخدم النسخ الاحتياطي JSON أو تصدير CSV ثم استعد/استورد الملف على الجهاز الآخر. المزامنة التلقائية بين الأجهزة تحتاج ربط خدمة سحابية وحسابًا، وهي غير مفعّلة في هذه النسخة؛ بيانات التطبيق تبقى محلية.
